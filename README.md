# ChatUIBeautify — AndroIDE build package

这是为手机端 AndroIDE 整理的 Android 项目。

## 项目入口
- `settings.gradle.kts`
- `build.gradle.kts`
- `app/`

## Android 环境
- compileSdk 34
- targetSdk 34
- minSdk 26
- JDK 17
- Android Gradle Plugin 8.6.1
- Kotlin 2.0.20

## 构建
在 AndroIDE 中以“现有 Android/Gradle 项目”方式打开本目录，然后执行构建 APK。
不要把 ZIP 文件本身当作代码文件复制到 `app/src`。

## 功能
- 黑白/浅灰手绘纸张风格
- 可编辑标题
- 可更换头像并保存
- 手绘虚线聊天气泡
- 左右消息布局
- 发送消息
- 顶部菜单
- 淡淡的背景手绘图案
